# ШАМ академия

React + Tailwind CSS + Supabase. Vercel-ге жариялауға дайын.

Жергілікті іске қосу (міндетті емес): `npm install` содан кейін `npm run dev`.

Supabase мәндері `src/lib/supabase.js` ішінде. Қаласаңыз, Vercel-де
`VITE_SUPABASE_URL` және `VITE_SUPABASE_KEY` айнымалылары арқылы ауыстыруға болады.
